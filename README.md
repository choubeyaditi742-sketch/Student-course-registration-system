# 🎓 Student Course Registration System

A simple **Student Course Registration System** developed using Python. This project allows students to register for courses, view their registered courses, drop courses, and check students enrolled in multiple courses.

The project is developed as part of a Python programming assignment (**Problem Statement No. 90**) using fundamental Python concepts.

## 🚀 Features

- **Student Registration:** Register students for available courses.
- **View Student Details:** Check a student's registered courses.
- **Drop Course:** Remove a student from a registered course.
- **View Course List:** Display all available courses and remaining seats.
- **Course Capacity Management:** Prevent registration when a course is full.
- **Duplicate Registration Check:** Prevent students from registering for the same course twice.
- **Maximum Course Limit:** Each student can register for a maximum of 3 courses.
- **Common Students:** Find students registered in two selected courses.
- **File Handling:** Save registration details in a text file so that data is available after restarting the program.

## 💻 How to Run the Project

**Step 1: Clone the repository**

```bash
git clone https://github.com/your-username/student-course-registration-system.git
```

**Step 2: Open the project folder**

```bash
cd student-course-registration-system
```

**Step 3: Run the Python file**

```bash
python student_course_registration_system.py
```

No external Python libraries are required.

## 📋 Main Menu

When you run the program, the following menu appears:

```text
1. Register
2. View student
3. Drop course
4. View course list
5. Students in two courses
6. Exit
```

Choose an option from 1 to 6 to perform the required operation.
